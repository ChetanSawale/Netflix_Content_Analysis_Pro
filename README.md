# Netflix Content Analysis Dashboard | Microsoft Power BI

## 📌 Project Overview

This project presents an interactive **Netflix Content Analysis Dashboard** developed using Microsoft Power BI.

The analysis explores Netflix's content library by examining movies and TV shows across different dimensions such as content type, ratings, release years, countries, genres, and listing categories.

The goal of this project is to transform raw Netflix title data into meaningful visual insights through interactive charts and dashboard visualizations.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze the distribution of Movies and TV Shows available in the dataset.
- Explore content ratings such as TV-MA, TV-14, PG-13, R, and others.
- Understand how Netflix content has grown across different release years.
- Identify countries contributing content to the Netflix catalog.
- Analyze content categories and genres using the `listed_in` field.
- Explore the distribution of titles added to Netflix over time.
- Compare content trends across years, countries, and ratings.

---

## 📊 Dashboard Analysis

The Power BI dashboard includes the following analytical views:

| Analysis Area | Description |
|---|---|
| Content Type | Comparison of Movies and TV Shows |
| Content Ratings | Distribution of titles across rating categories |
| Release Year Analysis | Number of titles released in different years |
| Country Analysis | Distribution of titles by country |
| Content Added Over Time | Analysis of titles added to Netflix by year |
| Genre / Category Analysis | Exploration of categories listed in the dataset |
| Year and Rating Trends | Comparison of content growth across years and ratings |

## 📁 Dataset Information

The project uses the **Netflix Titles Dataset**, which contains information about movies and TV shows available in the Netflix catalog.

### Dataset Columns

| Column | Description |
|---|---|
| `show_id` | Unique identifier assigned to each title |
| `type` | Type of content: Movie or TV Show |
| `title` | Name of the movie or TV show |
| `director` | Director or directors associated with the title |
| `cast` | Main cast members |
| `country` | Country or countries associated with the title |
| `date_added` | Date when the title was added to Netflix |
| `release_year` | Original release year of the title |
| `rating` | Content rating classification |
| `duration` | Movie duration or number of seasons for TV Shows |
| `listed_in` | Genres or categories associated with the title |
| `description` | Short description of the movie or TV show |

## 🔍 Key Analytical Questions

This project explores questions such as:

1. What is the distribution of Movies versus TV Shows?
2. Which content ratings appear most frequently in the dataset?
3. How has Netflix's content catalog changed over the years?
4. Which countries contribute the highest number of titles?
5. What are the most common genres or content categories?
6. How does the distribution of ratings change across release years?
7. In which years were the highest numbers of titles added to Netflix?
8. How do content trends differ between Movies and TV Shows?
